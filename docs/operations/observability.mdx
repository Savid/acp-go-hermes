# Observability

Use `WithLogger` for adapter diagnostics. The CLI `-debug` flag writes
structured logs to stderr. Stdout stays reserved for ACP JSON-RPC frames, so
diagnostics never mix into the protocol stream.

Embedded hosts supply OpenTelemetry providers with `WithTracerProvider`,
`WithMeterProvider`, and `WithTextMapPropagator`. The package never installs
global providers and never shuts down caller-supplied providers. The standalone
binary configures adapter exporters from standard `OTEL_*` environment
variables.

Telemetry records ACP request outcomes, prompt-turn timing, token usage, active
sessions, and `hermes serve` process starts. Inbound ACP `_meta` W3C trace
context is extracted for adapter spans and injected into each launched
`hermes serve` process as `TRACEPARENT`, `TRACESTATE`, and `BAGGAGE`.

Telemetry avoids recording prompt text, tool inputs, tool outputs, and raw
Hermes gateway event bodies by default.
