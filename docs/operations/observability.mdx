---
title: Observability
description: Wire logs, metrics, and traces for the adapter without leaking prompt content.
---

The adapter emits structured logs and OpenTelemetry signals for operators, and
keeps the ACP protocol stream clean.

## Logs

Use `WithLogger` for adapter diagnostics, or the CLI `-debug` flag to write
structured logs to stderr. Stdout stays reserved for ACP JSON-RPC frames, so
diagnostics never mix into the protocol stream.

## Traces and metrics

Embedded hosts supply OpenTelemetry providers with `WithTracerProvider`,
`WithMeterProvider`, and `WithTextMapPropagator`. The package never installs
global providers and never shuts down caller-supplied providers. The standalone
binary configures adapter exporters from the standard `OTEL_*` environment
variables.

Telemetry records ACP request outcomes, prompt-turn timing, token usage, active
sessions, and `hermes serve` process starts. A contained `hermes --version`
probe is admitted separately as `discovery` for both native-root and scratch-
root resource hooks; it is not hidden beneath the session admission. Inbound
ACP `_meta` W3C trace
context is extracted for adapter spans and injected into each launched
`hermes serve` process as `TRACEPARENT`, `TRACESTATE`, and `BAGGAGE`.

`acp_go_hermes.runtime.containment` records the selected `containment` mode as
`authoritative`, `shared_identity`, `best_effort`, or `unavailable`.
`shared_identity` is the ordinary default, reported on every supported platform
whenever `WithProcessIsolation` is omitted: native work runs as the adapter's
own identity, root or non-root alike. It is a non-authoritative posture rather
than a containment achievement, so it makes no whole-tree quiescence or
credential-separation claim and publishes no provider-process snapshots at all —
not even a terminal zero. Darwin best-effort startup also emits a structured
warning with `containment=best_effort`, and suppresses provider-process
snapshots for the same reason: it cannot authoritatively enumerate escaped
descendants, so a count would mislead even when it would read zero. Only
`authoritative` publishes provider-descendant inventory.

<Note>
Telemetry avoids recording prompt text, tool inputs, tool outputs, and raw
Hermes gateway event bodies by default.
</Note>
