# Prompt Streaming

Prompt turns call native `prompt.submit` over the Hermes WebSocket gateway and
consume gateway events until `message.complete`. `message.delta` events become
ACP text chunks, `thinking.delta` events become reasoning chunks, and token
data from completion payloads becomes `usage_update`.

If the WebSocket stream fails during a turn, the adapter aborts the native turn
and returns one terminal ACP error for that prompt. Idle disconnects are
treated as a gateway lifecycle failure and future session operations reconnect
through normal session hydration.
