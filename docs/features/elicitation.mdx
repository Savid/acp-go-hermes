# Elicitation

Hermes question events are reserved for ACP elicitation. The adapter records
client capabilities during initialize and must only send elicitation requests
when the client advertises the matching capability.

When `hermes serve` emits `clarify.request`, the adapter maps it to ACP
`elicitation/create` using the unstable form elicitation shape. If the ACP
client did not advertise form elicitation support, or if the client declines or
cancels the request, the adapter rejects the native Hermes question
deterministically.

`terminal.read.request`, `sudo.request`, and `secret.request` are not
forwarded as elicitation in v1. They are answered with deterministic empty
native responses and secrets are never persisted.
