---
title: Install
description: Install the adapter as a library or CLI and confirm the native Hermes prerequisites.
---

Install the CLI binary with the standard Go install idiom:

```sh
go install github.com/savid/acp-go-hermes/cmd/acp-go-hermes@latest
```

Or add the library to a Go module that embeds the adapter through `Serve`:

```sh
go get github.com/savid/acp-go-hermes
```

## Requirements

- Go matching the module's `go` directive (see `go.mod`).
- A local `hermes` CLI with `serve` support. The adapter launches it as
  `hermes serve`; point at a non-`PATH` binary with `-path` or
  `WithExecutablePath`.
- Provider credentials configured for Hermes for any live prompt to complete.

## Verify the install

```sh
acp-go-hermes -version
```

Smoke integration tests that do not spend provider tokens run under
`make test-integration-smoke`.

## Provision Linux identity authority

Linux installations must persist the shared identity-lock root:

```sh
sudo install -d -o root -g root -m 0700 \
  /var/lib/acp-go /var/lib/acp-go/agent-identities
```

Mount that exact local-lock volume into every service or container that can use
the same numeric UID pool, with identical user-namespace UID/GID mappings and
authoritative PID visibility. Otherwise use disjoint pools. Network, FUSE,
pseudo, read-only, and unknown authority filesystems are rejected. Files named
`<uid>.lock` are permanent and must never be unlinked, renamed, or replaced.
