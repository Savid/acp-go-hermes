# CLI

```sh
acp-go-hermes [flags]
```

Flags:

- `-path`: Hermes executable path; defaults to `hermes`
- `-home`: parent directory for isolated per-session Hermes homes
- `-model`: default model value passed as `provider/model`
- `-seed-file`: seed a file into each session's Hermes config root as
  `<relpath>=<hostpath>` (repeatable). The host file is read at startup and its
  contents are written to `<relpath>` under the isolated config root before
  hermes launches. Relative paths are confined to that root; absolute paths,
  `..` segments, and empty keys are rejected. Keep secrets out of seeded files
  and reference them by env-var indirection (hermes `key_env`) instead.
- `-debug`: enable debug logging on stderr
- `-version`: print the wrapper version and exit

Example, pointing hermes at a LiteLLM gateway:

```sh
acp-go-hermes -seed-file config.yaml=./hermes-config.yaml
```

No vendor-specific process flags are exposed in v1.
