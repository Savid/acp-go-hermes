The public API lives in package `hermesacp`. This page indexes the surface; exact
signatures and per-symbol contracts are on
[pkg.go.dev](https://pkg.go.dev/github.com/savid/acp-go-hermes).

## Entry points

```go
agent := hermesacp.NewAgent(opts...)
err := hermesacp.Serve(ctx, input, output, opts...)
```

`NewAgent` builds an `Agent` you own; `Serve` runs the ACP loop over a
reader/writer pair.

`ErrProcessContainmentIncomplete` is the stable `errors.Is` discriminator returned
when the selected native containment boundary cannot be completed. `Serve`
returns an `Agent.Close` error carrying this sentinel even when the stream
loop would otherwise return normally or with context cancellation. A host that
receives it must retain or quarantine any resources the native process tree may
still reach.

## Agent options

| Option | Purpose |
|---|---|
| `WithExecutablePath` | Path to the `hermes` binary (falls back to `hermes` on `PATH`). |
| `WithProcessIsolation` | Mandatory non-root UID/GID and complete replacement environment for native Hermes processes. On Linux the embedded supervisor stays trusted root; only `hermes serve` receives the configured identity, with supplementary groups cleared. |
| `WithScratchDir` | Sole parent directory for all ephemeral on-disk scratch (isolated per-session homes, sqlite temp dirs, process temp roots); empty means the system temp directory, created `0700` when missing. |
| `WithHome` | Unsupported because each session runtime root is isolated. Use `WithScratchDir` for ephemeral state and `WithProviderAuthHome` for durable provider credentials. |
| `WithDefaultModel` | Default `provider/model` for new sessions. |
| `WithEnv` | Environment overlaid on `ProcessIsolation.BaseEnvironment` for each `hermes serve` process. |
| `WithSeedFiles` | Files written into each session's config root before launch. |
| `WithSessionStore` | Durable `SessionStore` for persistence. |
| `WithSessionStoreLoadTimeout` | Bound on each store read (default 10s); writes use a fixed 60s bound. |
| `WithConcurrencyLimits` | `ConcurrencyLimits{MaxActiveSessions, MaxConcurrentClientCalls}`. |
| `WithImageLimits` | Decoded-byte limits for image prompt input; all four fields default to 6 MiB when omitted. |
| `WithProviderAuthRoot` | Absolute durable directory holding the values-free provider-auth ledger. Requires `WithProviderAuthHome`. |
| `WithProviderAuthDirectHome` | Unsupported. A non-empty value fails closed at session start. |
| `WithProviderAuthHome` | Absolute durable native credential residence supplied to every Hermes process as `HERMES_AUTH_HOME`. Requires `WithProviderAuthRoot`. |
| `WithInputHandoffRoot` | Absolute read-only root under which the host materializes local handoff image files; unset leaves the handoff prompt form rejected. |
| `WithTurnTimeout` | Per-turn deadline; `0` disables (see below). |
| `WithRuntimeResourceHooks` | Host admission hooks for native-process roots and adapter scratch roots. |
| `WithDarwinBestEffortContainment` | Explicitly accept Darwin process-group containment and its escaped-descendant, marker-scrubbing, and PGID-reuse risks. Rejected off Darwin. |
| `WithAgentName` / `WithAgentTitle` / `WithAgentVersion` | Advertised agent identity. |
| `WithLogger` | `*slog.Logger` for adapter diagnostics. |
| `WithTracerProvider` / `WithMeterProvider` / `WithTextMapPropagator` | OpenTelemetry providers. |

`ProcessIsolation.IdentityLock` and `ProcessIsolation.AuthorityDomain`
optionally accept opaque host capabilities with `Duplicate() (*os.File, error)`
for the already-held canonical UID lock and shared `domain.lock` lease. Each
capability keeps ownership of its original descriptor; caller-owned duplicates
reach only the trusted supervisor, which validates the named inodes, held locks,
and strict matching domain record and protects them with checked `FD_CLOEXEC`.
Set both fields together for
host-borrowed authority or leave both nil for standalone domain, disposition,
and UID-lock acquisition. A mixed nil/non-nil pair fails closed. Native
processes receive neither capability nor descriptor.

## Provider auth

`WithProviderAuthRoot` and `WithProviderAuthHome` are a required pair. The
former stores only connection lineage; the latter is canonicalized and supplied
to native Hermes as `HERMES_AUTH_HOME`. The adapter never exposes a public
credential type and never reads, copies, or returns native credential bytes.
See [Authentication](/docs/features/authentication).

`WithTurnTimeout(time.Duration)` bounds how long a single native turn may run
before the adapter interrupts it, completes its selected native containment
boundary, and fails the prompt with the uniform
`hermes_turn_failed` error whose `cause` is `timeout`. The default `0` disables
the deadline. A timeout is a failure, not a user cancel, so it is never reported
as the `cancelled` stop reason — see
[Prompt streaming](/docs/core/prompt-streaming).

Linux completion authoritatively empties the native tree. Windows native launch
is unavailable because the mandatory Unix UID/GID identity boundary with empty
supplementary groups cannot be applied; cross-compilation proves only that the
refusal path builds, not runtime support. Darwin best-effort completion means
only direct-child reaping plus absence of the captured original process group;
it does not establish that escaped descendants are gone.

`WithImageLimits(ImageLimits)` replaces all four image limits:
`MaxInputBytesPerImage`, `MaxInputBytesPerPrompt`,
`MaxOutputBytesPerImage`, and `MaxOutputBytesPerToolCall`. Limits count decoded
bytes. Omitting the option defaults every field to 6 MiB (6,291,456 bytes);
zero in a supplied struct disables that adapter policy limit, and a negative
field is rejected at agent construction. Hermes implements image prompt input;
it does not emit typed image output. The `MaxOutputBytesPerImage` and
`MaxOutputBytesPerToolCall` fields exist for API symmetry but Hermes never
consults them.

`WithInputHandoffRoot(dir string)` names the absolute directory under which a
co-located host has written handoff image files, enabling the
[local handoff form](/docs/core/prompt-streaming#local-handoff-image-input) and the
`acp-go.dev/handoff` advertisement. It is a read root, not a scratch root: the
adapter resolves, reads, and digest-verifies files there and never writes, moves,
or removes anything, so it does not compete with `WithScratchDir` for ephemeral
materialization. A relative path is rejected at agent construction. Omitting the
option leaves every handoff-form block rejected as `invalid_handoff` and the
capability unadvertised.

`RuntimeContainmentMode` reports `authoritative`, `best_effort`, or
`unavailable`. Embedded hosts can observe it through the runtime-resource
hooks. In best-effort mode provider-process snapshots are non-authoritative and
therefore suppressed, including zero-valued snapshots.

`WithSeedFiles` confines paths to the config root: absolute paths, `..`
segments, and empty keys are rejected at session start. `config.yaml` is the one
file the adapter itself authors (to carry the `mcp_servers` block); a seeded
`config.yaml` is deep-merged with the adapter's managed `mcp_servers` on top. All
other seeded files are written verbatim.

## Request builders

| Builder | Produces |
|---|---|
| `NewSessionRequest` / `LoadSessionRequest` / `ResumeSessionRequest` / `ForkSessionRequest` | Session lifecycle requests. |
| `PromptRequest` / `TextPromptRequest` | Prompt requests carrying a required per-turn nonce. |
| `CancelRequest` | Active-turn cancellation carrying the same nonce. |
| `StdioMCPServer` / `HTTPMCPServer` | MCP server definitions. |
| `SetModelRequest` / `SetConfigOptionRequest` | Config-option requests. |
| `ListSessionsRequest` | Session listing, with `WithListSessions*` options. |

Session requests take options such as `WithSessionMCPServers`,
`WithSessionAdditionalDirectories`, `WithSessionMeta`, `WithSessionHermesOptions`,
and `WithSessionRawEvents`.

`PromptRequest(sessionID, turnNonce, blocks...)` and
`TextPromptRequest(sessionID, turnNonce, text)` require a fresh, unguessable
nonce of at most 4096 bytes for every turn. `CancelRequest(sessionID,
turnNonce)` reuses it only for that active turn. Builders fail closed by
omitting the route envelope when given an empty or oversized nonce, so the
adapter rejects the resulting request.

`RuntimeResourceHooks` supplies `AcquireNativeRoot`, `ReserveScratchRoot`,
`ObserveProcess`, `ObserveProcessSnapshot`, and `ObserveStartupStage`.
Admission callbacks receive `runtime`, `session`, `prompt`, or `discovery`; nil
callbacks leave standalone operation unbounded. Hermes reserves the isolated
session home before creating it, holds the native permit for the one
`hermes serve` tree, and releases the reservation only after clean shutdown and
root deletion. Linux process snapshots include the dedicated per-session
subreaper plus every currently owned native descendant. Windows produces no
native-process snapshots because native launch is unavailable. Descendant
snapshots require authoritative containment; startup observations distinguish
spawn, readiness, configuration, and native session creation.

## Session store

The `SessionStore` interface is `Append`, `Load`, `Replace`, `Delete`,
`ListSessions`, and `ListSubkeys`. `NewInMemorySessionStore` returns a built-in
implementation. Supporting types: `SessionKey`, `SessionSummary`,
`SessionStoreReplacement`, and the `SessionStoreMainSubpath` /
`SessionStoreFormat` constants.

`InspectSessionStoreTerminalState(logicalSessionID, entries)` strictly
validates exactly one current-format main snapshot and returns its
`SessionStoreTerminalState`. The `MessageID` is empty before the first completed
assistant turn and otherwise contains the latest replay-stable `history-N`
identity.

## Session Hermes options

`HermesOptions` carries the `Model`, `Env`, and `OutputSchema` fields;
`NewHermesOptions` builds one from the `WithHermesModel`, `WithHermesEnv`, and
`WithHermesOutputSchema` constructor options. Setting a schema — through the
field or `WithHermesOutputSchema` — is accepted for API symmetry but fails
session start with the uniform unsupported-field error.
