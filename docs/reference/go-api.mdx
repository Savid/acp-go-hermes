# Go API

Primary entry points:

```go
agent := hermesacp.NewAgent()
err := hermesacp.Serve(ctx, input, output)
```

Common options include `WithExecutablePath`, `WithHome`, `WithDefaultModel`,
`WithEnv`, OpenTelemetry provider options, `WithSessionStore`, and
`WithConcurrencyLimits`.

Session `HermesOptions` include `WithHermesModel`, `WithHermesEnv`, and
`WithHermesOutputSchema`.

`WithHermesOutputSchema` is accepted for API symmetry but fails session start
with the uniform unsupported structured-output error. Native auth material must
be supplied through Hermes' own environment/configuration, not the ACP store.
