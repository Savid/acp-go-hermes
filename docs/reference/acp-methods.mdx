# ACP Methods

Stable methods:

- `initialize`
- `authenticate`
- `logout`
- `session/new`
- `session/load`
- `session/resume`
- `session/list`
- `session/prompt`
- `session/cancel`
- `session/close`
- `session/delete`
- `session/set_config_option`

`session/set_mode` returns method-not-found. Fork is only
`_hermes/session/fork`.

Command listing is intentionally silent in v1. MCP accepts stdio and HTTP
server definitions; SSE and ACP MCP definitions are rejected during session
start.
