# Metadata

Lifecycle requests accept:

```json
{
  "_meta": {
    "hermes": {
      "options": {
        "model": "provider/model",
        "env": {}
      },
      "rawEvent": {
        "enabled": false
      }
    }
  }
}
```

Unknown keys under `_meta.hermes` are rejected. Foreign namespaces are
ignored.

`_meta.hermes.options.model` selects the provider/model pair. `env` injects
per-session environment variables. No other option keys are accepted; any
unsupported field fails with an invalid-params `{"error":"unsupported"}`
response.
